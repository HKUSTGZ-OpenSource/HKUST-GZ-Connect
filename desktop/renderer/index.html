校园浏览器会自动使用上方规则；其他软件只有在你导出并手动导入后才会使用相应配置。

  1. Clash / Mihomo YAML 包含本机 SOCKS5 入口、学校基础规则和个人规则。
  2. VS Code 仅生成 Remote-SSH ProxyCommand 模板；你需要自行填写 Host、HostName 和 User。
  3. 规则变化后不会自动覆盖第三方文件；需要时请重新生成并再次导入。

配置可能含本机代理凭据或私有文件引用，但不含校园密码；请勿上传、同步或分享。
