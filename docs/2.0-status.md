## Current support statement

- HKUST(GZ) is the only packaged reviewed school Profile.
- `Other school` is visible in packaged 2.0 builds. It uses a credential-free public probe, one-use exact-origin
  confirmation, isolated storage and persistent unverified presentation; it does not by itself prove password
  auth, L3, Campus DNS, MFA or resource support.
- The repository supports multiple isolated Profile candidates and one active Profile at a time. It does not yet
  claim formally reviewed multi-school production compatibility.
- The production Gateway provider remains password + Modern L3. Generic MFA/control types and synthetic tests
  do not constitute a real school MFA provider.
- myPortal MFA is browser-owned: the user enters the SMS code manually in a managed child window; OTP values
  are neither autofilled from the campus password nor stored, logged or projected to Renderer state.

  with its loopback listener on `127.0.0.1:6180`; this is not a current process-status assertion.
- A SOCKS request to the school homepage returned HTTP 200. The HPC hostname resolved and completed HTTPS;
  the tested `/login` path returned HTTP 404 rather than a DNS/tunnel failure.
- A real installed Mihomo binary accepted the generated-compatible rule configuration and reached the school
  homepage through Mihomo → Campus Connect with HTTP 200; the disposable test configuration was removed.

  the exact tagged commit.

1. maintain the stable `2.0.x` line without expanding the product into SSH/HPC/Jupyter clients;
2. use a later patch line for subsequent maintenance rather than returning to the prerelease version;
3. keep the v1.2.3 migration fixture and three-platform package gates green for every update;
4. add a second reviewed Profile before claiming reviewed multi-school compatibility;
5. if the school later enables MFA on the VPN Gateway itself, open a separate task and implement it only from authorized,
   sanitized school evidence;
6. keep every later release bound to one exact tag, three-platform build and verified artifact set.

The application remains Web-resource-first for ordinary users and exposes external-tool configuration for
advanced users. It does not add an SSH client, HPC manager, Jupyter/database launcher or `ForwardLease`.
